# กรอบรูป CPE Open House (หน้าแต่งรูปบนมือถือ `/p/[code]`)

กรอบที่ใช้จริงอยู่ใน `cpe/` เป็น PNG แนวตั้ง **1080×1440** ช่องใส่รูปโปร่งใส หน้าแต่งรูปจะวาดรูปของน้องลงในช่อง แล้ววางกรอบทับ ไฟล์ที่บันทึกได้จึงมีขนาด 1080×1440

รายชื่อกรอบและตำแหน่งช่องรูปอยู่ใน `web/lib/mobile/frameTemplates.ts`

## เพิ่มหรือแก้กรอบ

ไฟล์ต้นฉบับจากผู้ออกแบบอยู่ที่ `template/CPE Open House/` ที่ root ของ repo ไฟล์จาก Canva ช่องรูปไม่โปร่งใส แต่มีรูปตัวอย่างท้องฟ้า ก้อนเมฆ และเนินหญ้าอยู่แทน สคริปต์จะลบรูปตัวอย่างนั้นออก และเก็บของตกแต่งที่วางทับช่องรูปไว้

1. วางไฟล์ใหม่ใน `template/CPE Open House/` ขนาด 1080×1440 และใช้รูปตัวอย่างเดียวกับไฟล์เดิม
2. รันจาก root ของ repo:
   ```powershell
   scripts\model-training\.venv\Scripts\python.exe scripts\frames\make_frame_overlays.py "template\CPE Open House" web\public\frames\cpe <โฟลเดอร์สำหรับรูปตรวจ>
   ```
   ลบไฟล์ `align_params.json` ใน `web\public\frames\cpe` ก่อนรัน สคริปต์จะได้หาตำแหน่งรูปตัวอย่างใหม่ ขั้นนี้ใช้เวลาหลายนาที
3. เปิดรูป `prev_<ชื่อ>.png` ในโฟลเดอร์รูปตรวจ ส่วนสีชมพูคือส่วนที่รูปของน้องจะแสดง
4. นำค่า `x, y, w, h` ที่สคริปต์แสดงออกมา ไปใส่ใน `FRAME_TEMPLATES` ใน `frameTemplates.ts`

ถ้าผู้ออกแบบ export จาก Canva แบบ "พื้นหลังโปร่งใส" และลบรูปในช่องออกก่อนได้ ก็ไม่ต้องใช้สคริปต์ วางไฟล์ใน `cpe/` ได้เลย

## ไฟล์อื่นในโฟลเดอร์นี้

ไฟล์ `template-*.png` เป็นภาพเปล่าจากโครงเดิม ใช้กับ `lib/mobile/useCanvasCompositor.ts` ซึ่งตอนนี้ไม่มีหน้าไหนเรียกใช้แล้ว
