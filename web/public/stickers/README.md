# สติกเกอร์ (หน้าแต่งรูปบนมือถือ `/p/[code]`)

วางไฟล์สติกเกอร์ไว้ในโฟลเดอร์นี้ได้เลย ไม่ต้องแก้โค้ด

- ใช้ได้: `.png` (แนะนำ พื้นโปร่งใส), `.webp`, `.svg`, `.gif`, `.jpg`
- ขนาดแนะนำ: ด้านยาว 400–800 px พื้นหลังโปร่งใส
- ลำดับในแถบสติกเกอร์เรียงตามชื่อไฟล์ เช่น `01-heart.png`, `02-star.png`

ตอนรัน `npm run dev` หรือ `npm run build` สคริปต์ `scripts/build-sticker-manifest.mjs` จะอัปเดตรายชื่อไฟล์ใน `stickers.json` ให้เอง ถ้าเพิ่มไฟล์ระหว่างที่ `npm run dev` เปิดอยู่ ให้ปิดแล้วรันใหม่ หรือรัน `node scripts/build-sticker-manifest.mjs`
