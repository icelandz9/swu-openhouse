## 1. สิ่งที่ต้องเตรียมล่วงหน้า (Prerequisites)

ติดตั้ง 3 โปรแกรมนี้บนเครื่องใหม่ (หากมีอยู่แล้วให้ข้ามขั้นตอนนี้):

1. **Node.js (แนะนำเวอร์ชัน 20 LTS หรือ 22 LTS)**
   - ดาวน์โหลด: [https://nodejs.org](https://nodejs.org) (เลือกปุ่มซ้ายที่เป็นเวอร์ชัน LTS)
   - ติดตั้งตามขั้นตอนมาตรฐาน (Next ➔ Next ➔ Finish)
   - เช็คว่าติดตั้งสำเร็จโดยเปิด Terminal หรือ PowerShell แล้วพิมพ์:
     ```bash
     node -v
     npm -v
     ```
2. **Git**
   - ดาวน์โหลด: [https://git-scm.com](https://git-scm.com)
   - ติดตั้งตามขั้นตอนมาตรฐาน
   - เช็คว่าติดตั้งสำเร็จ:
     ```bash
     git --version
     ```
3. **Google Chrome**
   - แนะนำให้ใช้ Google Chrome เป็นเบราว์เซอร์หลักเพื่อให้รองรับ MediaPipe WebGL และ BroadcastChannel API อย่างสมบูรณ์ 100%

## 2. ขั้นตอนการดึงโค้ดและติดตั้ง (Clone & Install)

เปิด **Terminal** (บน Mac/Linux) หรือ **PowerShell / Command Prompt** (บน Windows) แล้วทำตามขั้นตอนต่อไปนี้:

```powershell
# 1. ย้ายไปยังโฟลเดอร์ที่ต้องการเก็บโปรเจกต์ (เช่น Desktop)
cd Desktop

# 2. Clone โค้ดลงมาที่เครื่อง
git clone https://github.com/icelandz9/swu-openhouse.git

# 3. เข้าไปยังโฟลเดอร์โปรเจกต์
cd swu-openhouse

# 4. ติดตั้งแพ็กเกจ Dependencies ทั้งหมด
npm run setup
```

> **หมายเหตุเรื่องการตั้งค่า Cloud (.env):**  
> ไม่จำเป็นต้องสร้างหรือก๊อปปี้ไฟล์ `.env.local` ใดๆ ทั้งสิ้น ระบบได้ฝังค่าเชื่อมต่อ Cloudflare R2 สำหรับจัดเก็บรูป และ Vercel Production Domain (`https://cpe-swu-openhouse.vercel.app`) ไว้ในโค้ดให้อัตโนมัติแล้ว สามารถรันใช้งานได้ทันที

## 3. การเปิดใช้งานระบบ (Start System)

รันคำสั่งเดียวที่โฟลเดอร์หลักของโปรเจกต์:

```powershell
npm run dev
```

ระบบจะทำงานอัตโนมัติดังนี้:
1. สร้างเทมเพลตกรอบรูป 3 ลาย (`public/frames/`)
2. ดาวน์โหลดโมเดล MediaPipe Hand Landmark และไฟล์ WASM ลงในเครื่อง (`public/models/`)
3. สแกนและจัดทำดัชนีสติกเกอร์ 74 ลาย (`public/stickers/`)
4. สตาร์ท Next.js Dev Server บนพอร์ต 3000

เมื่อหน้าจอแสดงข้อความ:
```text
✓ Ready in 4s
- Local:   http://localhost:3000
- Network: http://0.0.0.0:3000
```
แปลว่าระบบพร้อมทำงานสมบูรณ์แล้ว!

## 5. การตั้งค่าจอแยกบน Windows (Windows Extend Mode)

เมื่อเสียบสายสัญญาณภาพ (HDMI หรือ Type-C) จากโน้ตบุ๊กไปยังจอทีวี 55–65 นิ้ว:

1. กดปุ่มลัด **`Windows Key + P`** บนคีย์บอร์ด
2. เลือกโหมด **"Extend" (ขยายหน้าจอ)**  
   *(⚠️ ข้อควรระวัง: ห้ามเลือก "Duplicate" เพราะภาพจะซ้ำกันทั้งสองจอ)*
3. **จัดวางหน้าต่าง:**
   - **บนจอโน้ตบุ๊ก:** เปิด Chrome แท็บ `http://localhost:3000/kiosk` แล้วกด **`F11`**
   - **บนจอทีวี:** ลากหน้าต่าง Chrome อีกหน้าต่างที่เปิด `http://localhost:3000/display` ข้ามไปที่จอทีวี แล้วกด **`F11`**

## 7. การแก้ปัญหาที่พบบ่อย (Troubleshooting FAQ)

### Q1: หน้าตู้ Kiosk ไม่ยอมเปิดกล้อง / จอดำ
- **สาเหตุ:** เบราว์เซอร์ยังไม่ได้รับอนุญาตให้ใช้กล้อง
- **วิธีแก้:** สังเกตไอคอนรูปกล้องถ่ายรูปที่แถบ URL ของ Chrome คลิกแล้วเลือก **"Always allow" (อนุญาตเสมอ)** จากนั้นกดรีเฟรชหน้าเว็บ หรือปิดแอปพลิเคชันอื่นที่อาจแย่งใช้งานกล้องอยู่ (เช่น Zoom, Teams, Camera App)

### Q2: ถ่ายรูปเสร็จแล้ว ภาพไม่เด้งไปขึ้นบนจอทีวี Showcase
- **สาเหตุ:** ทั้งสองหน้าจอเปิดคนละเบราว์เซอร์
- **วิธีแก้:** ตรวจสอบให้แน่ใจว่าทั้งหน้า `/kiosk` และหน้า `/display` ถูกเปิดบน **Google Chrome ตัวเดียวกัน บนเครื่องโน้ตบุ๊กเครื่องเดียวกัน** เพื่อให้เทคโนโลยี `BroadcastChannel` ซิงค์ข้อมูลระหว่างแท็บได้แบบเรียลไทม์ 0 latency

### Q3: รันคำสั่ง `npm run dev` แล้ว Error ว่าพอร์ต 3000 ไม่ว่าง (Port 3000 already in use)
- **วิธีแก้:** พิมพ์คำสั่งล้างพอร์ต:
  ```powershell
  npx kill-port 3000
  npm run dev
  ```
